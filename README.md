# MyOne 会场字幕助手下载

本仓库用于公开分发 MyOne 会场字幕助手的下载包和使用说明。

**[下载 0.1.2 · Windows x64 试用版](https://github.com/lc-Arvin/myone-caption-assistant-releases/releases/tag/v0.1.2)**

## 用途

在 PPT / WPS 放映画面上显示实时双语字幕。助手只接收字幕，收音与翻译继续使用 MyOne 服务；需要管理员提供有效的投屏码或本场投屏链接。

## 三步开始

1. 从 Releases 下载 Windows ZIP，完整解压整个文件夹。
2. 运行 `MyOne-Caption-Assistant.exe`，输入投屏码或直达链接。
3. 选择放映屏幕，点击“显示字幕”，再照常播放 PPT / WPS。

快捷键 `Ctrl + Shift + F9` 用于隐藏或恢复字幕。下载附件还包括中文快速使用说明和 SHA-256 校验文件。

当前为 Windows x64 未签名试用版；请在正式会场前使用实际设备彩排。GitHub 自动生成的 Source code 附件不是可运行应用。
