# ChestnutOne 会场字幕助手下载

本仓库公开分发 ChestnutOne 字幕助手的 Windows 下载包、版本记录和使用说明。

**[下载 0.2.0 · Windows x64 试用版](https://github.com/lc-Arvin/myone-caption-assistant-releases/releases/tag/v0.2.0)**

在 PPT / WPS 放映画面上叠加实时双语字幕。需要 MyOne 服务管理员提供有效投屏码或本场直达链接。

## 三步开始

1. 从 Releases 下载 Windows ZIP，完整解压整个文件夹。
2. 运行 `ChestnutOne-Caption-Assistant.exe`，输入投屏码或直达链接。
3. 选择放映屏幕，点击“显示字幕”，再照常播放 PPT / WPS。

选择预设或修改样式时先看预览，点击“立即生效”才会更新正式屏幕。`Ctrl + Shift + F9` 可隐藏／恢复字幕。最近房间和样式保存在本机。

当前为 Windows x64 未签名试用版，Windows 可能提示发行者未知；请在正式会场前使用实际设备彩排。GitHub 自动生成的 Source code 附件不是可运行应用。
