## ChestnutOne 字幕助手 0.2.0 · Windows x64 试用版

### 本次更新

- 全新 ChestnutOne 控制面板：连接、上屏和状态清晰分区。
- 五套场景预设：会议双语、舞台大字、培训课堂、浅色演示、高对比。
- 等比字幕预览：字号、字体、颜色、底色、位置和行数随设置立即更新；点击 **立即生效** 后才更新正式屏幕，也可撤销修改。
- 本机最近房间：保留最近 6 个成功的固定投屏码，点击填入，确认后连接；支持清空。
- 绿／黄／红活动信号，区分候场、暂停、无新字幕、重连与异常；错误详情包含错误码、时间、HTTP 状态及重试提示。
- 字幕显示进程异常后可恢复窗口，再重新上屏。连接新房间失败不会中断原连接。

### 下载与开始

1. 下载 **ChestnutOne-Caption-Assistant-Windows-x64-0.2.0.zip**，完整解压。
2. 运行 `ChestnutOne-Caption-Assistant.exe`，输入有效投屏码或本场直达链接。
3. 选择放映屏幕，点击“显示字幕”，照常播放 PPT / WPS。

快捷键 `Ctrl + Shift + F9` 隐藏／恢复字幕。附中文快速说明和 SHA-256 校验文件。GitHub 自动生成的 Source code 附件不是可运行应用。

当前为 **Windows x64 未签名试用版**，正式会场前仍需使用实际设备彩排。原独立投屏功能继续保留，旧版 [0.1.2](https://github.com/lc-Arvin/myone-caption-assistant-releases/releases/tag/v0.1.2) 保留供回退。
