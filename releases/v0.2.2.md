## ChestnutOne 字幕助手 0.2.2 · Windows x64 试用版

### 本次更新

- 字体扩展到 **17 项选择**：保留系统默认、无衬线、衬线，新增微软雅黑、等线、黑体、宋体、楷体、仿宋、苹方、思源黑体、思源宋体、Arial、Segoe UI、Times New Roman、Georgia、Verdana。
- 两种字幕语言可独立选字体。调整先更新预览，点击 **立即生效** 后更新正式输出并保存；重新打开、恢复字幕窗口后沿用已应用设置。
- 控制页提示本机字体可用情况。未安装时使用备用字体；实际字体取决于输出电脑，西文字体的中文字符可能使用中文备用字形。安装字体后请重新打开助手。
- 新增 ChestnutOne 专属程序图标，桌面、任务栏和运行窗口使用统一品牌图形。
- 保留五套预设、最近房间、活动信号、错误详情、网络及窗口恢复。兼容原有样式设置和投屏链接。

### 下载与开始

1. 下载 **ChestnutOne-Caption-Assistant-Windows-x64-0.2.2.zip**，完整解压整个文件夹。
2. 运行 `ChestnutOne-Caption-Assistant.exe`，输入有效投屏码或本场直达链接。
3. 选择放映屏幕，点击“显示字幕”，照常播放 PPT / WPS。
4. 展开“更多样式”，分别选择两种语言的字体，查看预览后点击“立即生效”。

快捷键 `Ctrl + Shift + F9` 隐藏／恢复字幕。附中文快速说明和 SHA-256 校验文件。应用使用本机字体，不附带字体字库。GitHub 自动生成的 Source code 附件不是可运行应用。

当前为 **Windows x64 未签名试用版**；已通过 Windows 程序运行、字体渲染、恢复及 OBS / WPS 软件检查，正式会场前仍需使用实际设备彩排。旧版 [0.2.0](https://github.com/lc-Arvin/myone-caption-assistant-releases/releases/tag/v0.2.0) 和 [0.1.2](https://github.com/lc-Arvin/myone-caption-assistant-releases/releases/tag/v0.1.2) 保留供回退。
